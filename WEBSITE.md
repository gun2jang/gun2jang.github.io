# Geonhee Jang — academic website

Live website: https://gun2jang.github.io/

The homepage is a dependency-free static website: `index.html`, `profile/style.css`, and `profile/favicon.svg`. `.nojekyll` disables the legacy theme build. Previous theme files, configuration, and posts are retained in the repository and Git history.

## Updating

- Edit `index.html` for content and the update date.
- Edit `profile/style.css` for layout and colors.
- Commit and push to the GitHub Pages source branch. Check **Settings → Pages** for the branch and source directory, and **Actions** for deployment status.
- No Node.js, Ruby, external fonts, analytics, or build step is needed for the homepage.

The page summarizes ongoing research without internal experimental results, infrastructure details, or private project links. The illustration is conceptual, not experimental data. No graduation date, future degree, author contribution markers, or performance claims are inferred. To preview locally, serve the repository root with a static web server.
